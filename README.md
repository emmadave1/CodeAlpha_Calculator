# CodeAlpha Calculator

A responsive, interactive calculator built with HTML, CSS, and JavaScript as part of the **CodeAlpha Frontend Development Internship**.

The calculator provides a clean, modern interface for performing arithmetic operations, with additional features designed to make calculations simple and convenient.

## Features

* **Basic Arithmetic:** Perform addition, subtraction, multiplication, and division.
* **Percentage Calculations:** Calculate percentages easily.
* **Decimal Support:** Perform calculations involving decimal numbers.
* **Sign Toggle:** Switch between positive and negative numbers.
* **Clear Function:** Reset the current calculation.
* **Delete Function:** Remove the last entered character.
* **Keyboard Support:** Perform calculations using your keyboard.
* **Calculation History:** View previous calculations.
* **Error Handling:** Handles invalid operations, including division by zero.
* **Responsive Design:** Works across desktop, tablet, and mobile screen sizes.
* **Modern Interface:** Features a dark-themed design with purple accents.

## Technologies Used

* **HTML5** — Structures the calculator interface.
* **CSS3** — Provides styling, layout, animations, and responsive design.
* **JavaScript** — Implements the calculator's logic, keyboard interactions, and calculation history.

## Getting Started

### Prerequisites

You need a modern web browser, such as Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/emmadave1/CodeAlpha_Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd CodeAlpha_Calculator
   ```

3. Open `index.html` in your browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension to run the calculator locally.

## Keyboard Shortcuts

| Key         | Function                      |
| ----------- | ----------------------------- |
| `0–9`       | Enter numbers                 |
| `+`         | Addition                      |
| `-`         | Subtraction                   |
| `*`         | Multiplication                |
| `/`         | Division                      |
| `.`         | Enter a decimal point         |
| `Enter`     | Calculate the result          |
| `Backspace` | Delete the last character     |
| `Escape`    | Clear the current calculation |
